Scan Mode

How to search GBIF for interaction records.

Stream 1: Searches taxonKey=<target> + each interaction keyword. Finds records where the target organism is the occurrence, with interaction evidence in remarks/notes.
Stream 2: Searches all of GBIF with q="<interaction_term> <target_name>". Finds enemy-organism records (spiders, wasps, etc.) whose remarks mention the target as prey/host. Checks occurrenceRemarks, fieldNotes, behavior, associatedTaxa, and 8 other DwC text fields.

Predator / Parasite Taxon List (optional)

Paste your list of predator / parasite taxa — one per line, or comma/semicolon separated. Each name is looked up on the GBIF backbone, a common/vernacular name is resolved (falling back genus → family → order), and that name is searched against target occurrences in GBIF.
